# Frontend (Expo + React Native + TypeScript + Tailwind)

## Commands

```bash
npm install
npm run web
```

Optional native runs:

```bash
npm run android
npm run ios
```

## Notes

- Tailwind is provided through `nativewind`.
- `npm run web` is the fast path for UI iteration.
- Native APIs (microphone, GPS, notifications, background tasks) must still be validated on device/emulator.
